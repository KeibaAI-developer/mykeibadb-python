# analyze_chakudo 実装

## 概要
グループ別着度数・勝率・回収率を集計する `analyze_chakudo` を実装する。
`mykeibadb-mcp-server` の `analyze_race_chakudo` を汎用化して `mykeibadb.analytics` モジュールに移植し、公開 API として提供する。

## 変更内容

### 新規作成ファイル
- `mykeibadb/analytics/chakudo.py`: `analyze_chakudo` 関数
  - `group_expr` / `sort_expr` を SQL 式として外部から注入し、任意グループ集計に対応
  - `kakutei_chakujun ~ '^[0-9]{2}$'` で取消レースを除外
  - `build_payout_ctes` を使って単勝・複勝回収率を計算
  - `course_kubun` + `week_in_course` 両方指定時に `build_course_week_cte` で CTE 生成
  - 片方のみ指定時は `ValueError` を raise
  - `MykeibaDBError` をキャッチして `ChakudoResult(success=False)` を返す

### 既存ファイルの変更
- `mykeibadb/analytics/__init__.py`: `analyze_chakudo` / `ChakudoRow` / `ChakudoResult` のエクスポートを追加

## テスト内容

### 新規作成ファイル
- `test/unit/mykeibadb/analytics/test_chakudo.py`: 9 件のテスト
  - 正常系: success=True、フィルタ引数が SQL パラメータに渡る、空 DataFrame、NaN → 0.0、course_week CTE 生成、keibajo が WHERE に入る
  - 準正常系: course_kubun のみ指定で ValueError、week_in_course のみ指定で ValueError、DB エラーで success=False
